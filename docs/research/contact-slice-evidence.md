## The compiler prerequisite, observed and then delivered

The first truthful Contact declaration failed `effx check --strict-access` with `EFFX2501: Command access cannot decide in a read snapshot`. This was not a wire-contract concession: the existing access rule has always decided at `SnapshotRead`. The compiler owner delivered a narrow, explicit opt-in (ADR 0013): `snapshotDecisionForCommand: true` on `Http.Access` options only, valid solely for a Command with `SnapshotRead`, no requirements, exactly the `ObjectCapability` credential and exactly the `CapabilityHolder` principal. Any other shape reports `EFFX2506`; an unsafe Command keeps `EFFX2501`. Absent or `false`, no IR, hash or generated byte changes.
