Add the pure lift core of spec 0019 (seam S7). `@effx/compiler` exports the Schema-defined frontend-to-core model (`EffectModel`: endpoint, group, root and binding records over the one neutral `Term`, typed native Effect identity claims validated against the generator's own target table, source ranges and findings; an unlowerable node is an `Unlowered` slot, never a partial term), the data rules (`LiftRule`, `LiftInput`) that stand in for application helpers, the abstract `LiftFrontend` capability (`analyze(project)`, no production layer in the compiler) and the pure, total `lift(model, input)`. It returns a `LiftResult`: a verbose `Collected` the existing pipeline compiles, wire-preserving refactors as typed edits with real planned references (EFFX3002 inline request schemas, EFFX3003 inline response headers, EFFX3004 problem code tuples), the decisions to review, every unsupported declaration with all its causes ordered by source position, the unresolved adapter prerequisites and the static binding reports. `dense` returns the dense rewrite only after the group-defaults pre-pass rebuilds the verbose declarations exactly, `printSuggestion` writes either form as builder source with real imports, and `renderPatch` prints the refactors as a unified diff after verifying the SHA-256 of each analyzed file, without applying them. The `Terms` namespace re-exports the one existing term algebra and printer. The EFFX3001-3010, EFFX3101-3103 and EFFX3201-3202 diagnostics are registered with owner `lift`; `@effx/diagnostics` reserves the `30`, `31` and `32` families for that owner.
